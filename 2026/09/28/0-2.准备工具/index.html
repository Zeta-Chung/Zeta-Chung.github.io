常用Linux命令

通用格式

命令 [选项] [参数]

例： ls -l /home ，-l是选项，/home是参数
可使用man 查看每个命令的具体选项

pwd

  1. 作用：打印当前工作目录(Print Working Directory)

  2. 选项：-P：显示物理路径

  3. 使用方法：pwd 或 pwd -P

ls

  1. 作用：列出文件和目录(list)

  2. 常用选项

    选项 作用
    -l 长格式显示，包含权限、所有者、大小、时间
    -a 显示隐藏文件，包括 . 和 …
    -h 人类可读大小，如 1K、2M
    -t 按修改时间排序
    -r 反向排序
    -R 递归列出子目录

  3. 示例

cd

  1. 作用：切换当前工作目录(change directory)

  2. 示例

    • cd /file：从根目录开始切换绝对路径到file

    • cd file：从当前目录开始切换相对路径到file

    • cd . : 切换目录层级（有n个.表示往上切换n-1级）

    • cd ~ : 切换到根目录

    • cd - ：切换到上一次所在目录

mkdir

  1. 作用：创建目录(make directory)

  2. 常用选项

    • -p：递归创建多级目录，父目录不存在也自动创建

    • -m：创建时指定权限.只对创建的新目录生效，不会修改已存在目录的权限

  3. 示例

touch

  1. 作用：创建文件或更新时间戳

  2. 示例

    -a 归档模式，保留权限、时间等，常用于备份

mv

常用操作

文件描述符（fd）

是什么

  1. fd（file descriptor，文件描述符）其实就是“打开文件/终端/管道的编号”。

  2. 内核给每个进程维护一张表，这张表里每个条目都对应一个“打开的对象”。

  3. 程序读写时，不需要直接记住对象本身，只要知道它的编号就行。

fd 不是文件内容，而是“这个对象在进程里的入口编号”。

为什么需要

  • 每个进程都有自己的 fd 表

  • 这个表是进程自己的，不同进程的 fd 0、1、2 可能指向不同对象

  • 只要拿到 fd 编号，程序就能对对应的输入输出对象进行读写

command > file

  1. 是什么：让标准输出重定向，覆盖写入

  2. 怎么做：使command 的标准输出fd1指向file，然后执行command,向fd1（即file）写入

    1. 如果 file 不存在，会创建。

    2. 如果 file 已存在，会先清空，再写入。

    3. 只重定向 stdout，不处理 stderr。

    4. 等价于 command 1> file。

  3. 示例：echo "hello" > out.txt，把 hello 写进 out.txt，而不是直接显示到屏幕。

command >> file

  1. 是什么：标准输出重定向，追加写入。

  2. 怎么做：把 command 的标准输出追加到 file 末尾。

    1. 如果 file 不存在，会创建。

    2. 如果 file 已存在，不会清空，而是在末尾追加。

    3. 等价于 command 1>> file。

command < file

  1. 是什么：标准输入重定向

  2. 怎么做：将command的fd0指向file的内容，再执行command，这样就把file的内容作为command的标准输入，也就是让command从file读取。

  3. 示例：cat < file.txt表示让 cat 不从键盘读，而是从 file.txt 读。等价于：cat 0< file.txt

command1 | command2

  1. 是什么：管道

  2. 怎么做：把command1的标准输出作为command2的标准输入。也可理解为：将command1 的输出，传给 command2 处理。

    1. 管道只传递 stdout，不传递 stderr。

    2. 如果左边命令报错，错误信息默认还是输出到屏幕。

    3. 右边命令通常不需要再写文件名，它直接从标准输入读。
