补码编码

是什么

补码编码是一种用于表示有符号整数的编码方式，它允许计算机在进行加减运算时无需区分正负数，从而简化了硬件设计。

函数B2Tω(x⃗)B2T_{\omega}(\vec{x})B2Tω​(x)将二进制向量x⃗\vec{x}x映射为一个补码整数XXX，这是一个双射，即每个二进制向量对应一个唯一的补码整数，反之亦然。

原因：0占用了一个补码整数的表示范围，导致负数的表示范围比正数多一个。

扩展一个数字的位表示

是什么

将一个数字的位表示从ω\omegaω位扩展到ω+k\omega + kω+k位，其中k≥0k \geq 0k≥0，以便在更大的位宽下进行运算。扩展的方式取决于数字的类型（无符号或补码）。

为什么需要

在计算机中，处理器的字长可能会发生变化，例如从32位扩展到64位。在这种情况下，需要将原有的数字表示扩展到新的位宽，以确保计算的正确性和一致性。

是什么

定义宽度为ω\omegaω的位向量u⃗=[uω−1,uω−2,…,u1,u0]\vec{u} = [u_{\omega-1}, u_{\omega-2}, \ldots, u_1, u_0]u=[uω−1​,uω−2​,…,u1​,u0​]，其对应的无符号整数为U=B2Uω(u⃗)U = B2U_{\omega}(\vec{u})U=B2Uω​(u)。将其扩展到宽度为ω′(ω′>ω)\omega'(\omega' > \omega)ω′(ω′>ω)的位向量u′⃗=[0,0,…,0,uω−1,uω−2,…,u1,u0]\vec{u'} = [0, 0, \ldots, 0, u_{\omega-1}, u_{\omega-2}, \ldots, u_1, u_0]u′=[0,0,…,0,uω−1​,uω−2​,…,u1​,u0​]，其中前kkk位填充为0。则有

B2Uω′(u′⃗)=B2Uω(u⃗)=UB2U_{\omega'}(\vec{u'}) = B2U_{\omega}(\vec{u}) = U B2Uω′​(u′)=B2Uω​(u)=U

原理

遵循零扩展的原则，前kkk位填充为0，不会改变原有数字的值，因此扩展后的无符号整数与原无符号整数相等。

是什么

定义宽度为ω\omegaω的位向量x⃗=[xω−1,xω−2,…,x1,x0]\vec{x} = [x_{\omega-1}, x_{\omega-2}, \ldots, x_1, x_0]x=[xω−1​,xω−2​,…,x1​,x0​]，其对应的补码整数为T=B2Tω(x⃗)T = B2T_{\omega}(\vec{x})T=B2Tω​(x)。将其扩展到宽度为ω′(ω′>ω)\omega'(\omega' > \omega)ω′(ω′>ω)的位向量x′⃗=[xω−1,xω−1,…,xω−1,xω−2,…,x1,x0]\vec{x'} = [x_{\omega-1}, x_{\omega-1}, \ldots, x_{\omega-1}, x_{\omega-2}, \ldots, x_1, x_0]x′=[xω−1​,xω−1​,…,xω−1​,xω−2​,…,x1​,x0​]，其中前kkk位填充为符号位xω−1x_{\omega-1}xω−1​。则有

B2Tω′(x′⃗)=B2Tω(x⃗)=TB2T_{\omega'}(\vec{x'}) = B2T_{\omega}(\vec{x}) = T B2Tω′​(x′)=B2Tω​(x)=T

原理

扩展前的值表示为

T=−xω−12ω−1+∑i=0ω−2xi2iT = -x_{\omega-1} 2^{\omega-1} + \sum_{i=0}^{\omega-2} x_i 2^i T=−xω−1​2ω−1+i=0∑ω−2​xi​2i

T′=−xω−12ω′−1+∑i=ω−1ω′−2xi2i+∑i=0ω−2xi2iT' = -x_{\omega-1} 2^{\omega'-1} + \sum_{i=\omega-1}^{\omega'-2} x_i 2^i+ \sum_{i=0}^{\omega-2} x_i 2^i T′=−xω−1​2ω′−1+i=ω−1∑ω′−2​xi​2i+i=0∑ω−2​xi​2i

截断数字

是什么

将一个数字的位表示从ω\omegaω位截断到ω−k\omega - kω−k位，其中k≥0k \geq 0k≥0，以便在更小的位宽下进行运算。截断的方式取决于数字的类型（无符号或补码）。

为什么需要

在计算机中，处理器的字长可能会发生变化，例如从64位截断到32位。在这种情况下，需要将原有的数字表示截断到新的位宽，以确保计算的正确性和一致性。

无符号数的截断

是什么

定义宽度为ω\omegaω的位向量x⃗=[xω−1,xω−2,…,x1,x0]\vec{x} = [x_{\omega-1}, x_{\omega-2}, \ldots, x_1, x_0]x=[xω−1​,xω−2​,…,x1​,x0​]，其对应的无符号整数为U=B2Uω(x⃗)U = B2U_{\omega}(\vec{x})U=B2Uω​(x)。将其截断到宽度为k(k<ω)k(k < \omega)k(k<ω)的位向量x′⃗=[xk−1,xk−2,…,x1,x0]\vec{x'} = [x_{k-1}, x_{k-2}, \ldots, x_1, x_0]x′=[xk−1​,xk−2​,…,x1​,x0​]，则有

B2Uk(x′⃗)=xmod2kB2U_{k}(\vec{x'}) = x mod 2^{k} B2Uk​(x′)=xmod2k

原理

所有截去的高位权重都是2k2^{k}2k的倍数，对2k2^{k}2k取模都为0，因此截断后的无符号整数等于原无符号整数对2k2^{k}2k取模的结果。

补码数的截断

是什么

定义宽度为ω\omegaω的位向量x⃗=[xω−1,xω−2,…,x1,x0]\vec{x} = [x_{\omega-1}, x_{\omega-2}, \ldots, x_1, x_0]x=[xω−1​,xω−2​,…,x1​,x0​]，其对应的补码整数为T=B2Tω(x⃗)T = B2T_{\omega}(\vec{x})T=B2Tω​(x)。将其截断到宽度为k(k<ω)k(k < \omega)k(k<ω)的位向量x′⃗=[xk−1,xk−2,…,x1,x0]\vec{x'} = [x_{k-1}, x_{k-2}, \ldots, x_1, x_0]x′=[xk−1​,xk−2​,…,x1​,x0​]，则有

B2Tk(x′⃗)=U2Tk(B2Uω(x⃗)mod2k)B2T_{k}(\vec{x'}) = U2T_{k}(B2U_{\omega}(\vec{x}) mod 2^{k}) B2Tk​(x′)=U2Tk​(B2Uω​(x)mod2k)

先看作无符号整数U=B2Uω(x⃗)U = B2U_{\omega}(\vec{x})U=B2Uω​(x)，然后对2k2^{k}2k取模，得到截断后的无符号整数U′=Umod2kU' = U mod 2^{k}U′=Umod2k。最后将U′U'U′转换为补码整数T′=U2Tk(U′)T' = U2T_{k}(U')T′=U2Tk​(U′)，得到截断后的补码整数。

原理

除以2的幂的无符号除法

对于变量x和k有无符号数值x和k，且0≤k<ω0 \leq k < \omega0≤k<ω，则有：

⌊x2k⌋=x>>k\lfloor \frac{x}{2^k} \rfloor = x >> k ⌊2kx​⌋=x>>k

（向下取整的除法）

为什么需要

用移位运算替代整数除法能够大大节省时钟周期，尤其是在处理大整数时。移位运算的时间复杂度为O(1)，而整数除法的时间复杂度为O(log n)。

原理

除以2的幂相当于将位模式向右移动kkk位

除以2的幂的补码除法

  1. 对于变量x和k有补码数值x和无符号数值k, 且0≤k<ω0 \leq k < \omega0≤k<ω，当执行算数移位时，产生数值⌊x2k⌋\lfloor \frac{x}{2^k} \rfloor⌊2kx​⌋，这是向下取整的除法。

右移产生的高位应该取决于符号位的值，如果符号位为1，则高位填充为1，否则填充为0。这种方式保证了除法结果的正确性，尤其是在处理负数时。

  1. 对于变量x和k有补码数值x和无符号数值k，且0≤k<ω0 \leq k < \omega0≤k<ω，当执行算数移位时，C表达式(x+(1<<k)-1)>>k产生数值⌊x2k⌋\lfloor \frac{x}{2^k} \rfloor⌊2kx​⌋，这是向零取整的除法。

专用于x<0的情况，x>0的情况和无符号数值的除法相同。
